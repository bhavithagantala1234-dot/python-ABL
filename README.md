## About the Project

This project contains 10 Python case studies developed as part of the Python Activity-Based Learning assignment. These programs solve real-world problems using basic Python programming concepts.

## Case Studies

### Case Study 1: Progressive Electricity Billing
Calculate electricity bills based on different consumption slabs.

### Case Study 2: Retail Billing with Multiple Discount Rules
Calculate product bills using quantities and discount conditions.

### Case Study 3: Attendance Recovery Computation
Calculate attendance percentage and minimum extra classes required.

### Case Study 4: ATM Transaction Sequence Simulation
Simulate deposits, withdrawals and balance checking.

### Case Study 5: Student Performance Trend Analysis
Compare examination marks and analyse student performance.

### Case Study 6: Multi-Product Shopping Budget Constraint
Calculate shopping costs and check the available budget.

### Case Study 7: Advanced Numeric Pattern Generator
Generate numeric patterns using nested loops.

### Case Study 8: Password Policy Validation Engine
Validate passwords using basic password conditions.

### Case Study 9: Student Marks Matrix Analysis
Calculate student totals, averages and identify top performers.

### Case Study 10: Smart Canteen Order and Stock Management
Calculate food bills and update available stock.
